# 龍門架尺寸與重量方案比較

> 日期: 2026-05-31  
> 目的: 將量測範圍、龍門架尺寸、移動重量與 SKR Pico / TMC2209 驅動能力納入第一版 AOI 機構決策。

## 1. 方案定義

| 方案 | 有效量測範圍 | 定位 | 初步建議 |
|:---|:---:|:---|:---|
| 方案一 | 620 x 550 mm | 大面積 PCB / 泛用平台 | 可行，但機構重量、長皮帶回彈與共振控制風險較高 |
| 方案二 | 320 x 300 mm | 小型 PCB / 第一版驗證機 | **第一版指定採用**：CoreXY + GT2 9mm 同步帶 |

有效量測範圍不是外框尺寸。機構外框通常需額外預留：

- 相機模組與鏡頭外徑。
- X/Y 軸滑車與端板厚度。
- 原點與極限緩衝距離。
- 拖鏈與線材彎曲半徑。
- PCB 夾具或真空平台邊界。

## 2. 建議外框尺寸估算

| 方案 | 有效量測範圍 | 建議外框尺寸估算 | 說明 |
|:---|:---:|:---:|:---|
| 方案一 | 620 x 550 mm | 約 780 x 700 mm | 接近原 BOM 800 x 600mm 等級，但 Y 向需更深，實際外框可能接近 800 x 700mm |
| 方案二 | 320 x 300 mm | 約 480 x 450 mm | 體積、重量、皮帶長度與拖鏈需求明顯下降 |

估算預留量:

```text
X 外框寬度 = 有效 X + 120~180 mm
Y 外框深度 = 有效 Y + 120~180 mm
```

實際尺寸需等相機固定座、光源、PCB 固定方式確定後再定版。

## 3. 重量與慣量影響

AOI 不是單純能不能移動，而是移動後能不能快速穩定拍照。龍門越大，問題不只線性增加：

- X 橫樑更長，重量增加且撓曲更明顯。
- CoreXY 長皮帶需要維持一致張力，且 X gantry 越重，停止後殘留震動越明顯。
- GT2 9mm 比 6mm 更適合此平台，但仍需用 Input Shaping 與 settling delay 控制回彈。
- 停止後殘留震動較大，拍照前 settling time 變長。
- SKR Pico 板載 TMC2209 雖可驅動 NEMA17，但不適合過重龍門或高加速度。

### 3.1 移動重量粗估

| 項目 | 方案一 620 x 550 | 方案二 320 x 300 | 影響 |
|:---|:---:|:---:|:---|
| X 橫樑長度 | 約 700~780mm | 約 420~480mm | 方案一橫樑更重、更容易震 |
| CoreXY 皮帶長度 | 長 | 短 | 方案一張力與共振控制更敏感 |
| 拖鏈長度 | 高 | 低 | 方案一線材阻力較大 |
| 移動慣量 | 高 | 低 | 方案二更容易用板載 TMC2209 穩定驅動 |
| 拍照穩定時間 | 較長 | 較短 | 方案二吞吐量較好 |

## 3.2 CoreXY / GT2 9mm 傳動影響

第一版傳動方案指定為 **CoreXY + GT2 9mm 同步帶**。這對 AOI 有幾個明確變化:

| 項目 | 影響 |
|:---|:---|
| 速度 | 優於絲杆，適合多點掃描 |
| 重量 | 較輕，對 SKR Pico 板載 TMC2209 較友善 |
| 回彈 / 共振 | 需靠張力、剛性、Input Shaping 與拍照前等待控制 |
| 組裝難度 | 低於絲杆，但 belt path 高度與 pulley/idler 共面很重要 |
| 放大風險 | 620 x 550mm 皮帶變長後，共振與張力一致性更敏感 |

指定規格:

| 零件 | 規格 |
|:---|:---|
| 同步帶 | GT2 / 2GT, 9mm width |
| 馬達同步輪 | GT2 20T pulley, 9mm belt, 5mm bore |
| 惰輪 | GT2 20T toothed idler, 9mm belt, 5mm bore |
| Klipper kinematics | `corexy` |

Klipper `rotation_distance`:

```text
20T * 2mm pitch = 40mm/rev
rotation_distance = 40
```

## 4. 對 SKR Pico / TMC2209 的影響

SKR Pico 板載 TMC2209 適合 NEMA17 與輕中載 XY 平台。它的優點是安靜、整合度高、Klipper 設定方便；限制是散熱與可持續電流不如外接 TB6600 / DM542。

| 評估項 | 方案一 620 x 550 | 方案二 320 x 300 |
|:---|:---|:---|
| SKR Pico 板載驅動可行性 | 可行但需保守速度/加速度與良好散熱 | 高可行 |
| 馬達建議 | NEMA17 1.5A+，CoreXY A/B 雙馬達 | NEMA17 1.2~1.5A 足夠機率高 |
| TMC2209 電流 | 可能需 0.9~1.1A RMS | 可從 0.7~0.9A RMS 起測 |
| 散熱 | 必須加風扇吹板 | 建議加風扇，但壓力較小 |
| 加速度 | 建議保守 | 可稍高，但仍以低震動為主 |
| 是否可能需要外接驅動 | 若長皮帶、高張力或 gantry 過重，可能 | 低 |

初始 Klipper 建議:

| 參數 | 方案一 | 方案二 |
|:---|:---:|:---:|
| `max_velocity` | 80~120 mm/s 起測 | 100~150 mm/s 起測 |
| `max_accel` | 300~600 mm/s² | 300~800 mm/s² |
| 拍照前 settling delay | 150~300 ms 起測 | 100~200 ms 起測 |
| TMC2209 `run_current` | 0.9A 起測 | 0.75A 起測 |
| TMC2209 `hold_current` | 0.4~0.6A | 0.3~0.5A |

以上不是最終值，實機需用 ADXL345 或拍照清晰度測試調整。

## 5. 光學與掃描效率影響

目前光學設計目標 FOV 約 30 x 30 mm。若每個視野保留重疊，例如 25mm step pitch：

| 方案 | 有效量測範圍 | 約略拍照點數 |
|:---|:---:|---:|
| 方案一 | 620 x 550 mm | 約 25 x 22 = 550 點 |
| 方案二 | 320 x 300 mm | 約 13 x 12 = 156 點 |

若單點流程為:

```text
移動 + settling + 拍照 + 推論 + 存檔 = 0.5~1.0 秒
```

則:

| 方案 | 估計掃描時間 |
|:---|:---|
| 方案一 | 約 4.5~9 分鐘 |
| 方案二 | 約 1.3~2.6 分鐘 |

方案一不只機構較重，點數也多很多，對長時間穩定性、資料量與 UI Review 都會放大壓力。

## 6. 機構設計建議

### 6.1 方案一 620 x 550

適合:

- 需要覆蓋較大 PCB。
- 接受較慢掃描速度。
- 願意投入較多機構調整時間。

建議:

- 使用 CoreXY A/B 雙 NEMA17。
- X 橫樑不建議過細，若用 2020 需評估撓曲，2040 或輕量加強結構更穩。
- SKR Pico 必須加主動散熱。
- 加速度與速度需保守設定，避免長皮帶回彈造成拍照模糊。
- 兩條 CoreXY belt 張力需一致，pulley / idler 高度需共面。
- 拖鏈線材要輕、柔、固定良好，避免拖鏈阻力拉偏 X gantry。

風險:

- 板載 TMC2209 在高負載、高加速度下可能過熱或失步。
- CoreXY belt path 與張力一致性較敏感。
- 長皮帶張力不均與 idler 不共面會影響定位與影像穩定。

### 6.2 方案二 320 x 300

適合:

- 第一版工程驗證。
- 小型 PCB / 局部 AOI。
- 優先讓相機、推論、運動整合先跑穩。

建議:

- 採用 CoreXY A/B 雙馬達配置，保留與 Voron 類 CoreXY 生態相容的 belt path。
- X 橫樑可用 2020 V-Slot，重量較低。
- SKR Pico 板載 TMC2209 更有餘裕。
- 較容易縮短 settling delay，提高掃描效率。
- 皮帶較短，張力、回彈與共振風險比方案一低很多。

優點:

- 成本更低。
- 震動更小。
- 組裝校正更容易。
- 對 Pi 5 4GB 與資料管理壓力較小。
- 第一版失敗成本低，後續可按同架構放大。

## 7. 建議決策

第一版建議採用 **方案二: 320 x 300 mm 有效量測範圍**。

理由:

1. 更符合 SKR Pico 板載 TMC2209 的穩定負載區間。
2. 可縮短 GT2 9mm 同步帶與拖鏈，降低回彈、震動與調機難度。
3. 掃描點數約為方案一的 28%，資料量與掃描時間明顯降低。
4. 更適合作為 AOI 軟體、相機、Klipper / Moonraker 整合驗證平台。
5. 若流程穩定，後續可將同一套架構放大到 620 x 550。

方案一可保留為第二階段放大版。在放大前，應先用方案二測得:

- 單點拍照清晰度。
- 移動後 settling delay。
- XY 重複定位誤差。
- 馬達與 SKR Pico 溫度。
- 每小時連續掃描穩定性。
- 影像資料量與 Pi 5 4GB RAM 峰值。

## 8. 對現有 BOM 的影響

原 BOM 的「Gantry Mechanics 800x600mm」需改成候選尺寸。若選方案二，以下項目可下修:

- 鋁擠型長度。
- GT2 9mm 同步帶長度。
- GT2 20T pulley / toothed idler 數量。
- 拖鏈長度。
- 線材長度。
- 龍門板尺寸。
- 可能降低馬達電流與散熱壓力。

仍建議保留:

- 三顆 NEMA17。
- SKR Pico。
- 24V 電源。
- 三個限位開關。
- ADXL345，用於量測震動與 Input Shaping。
